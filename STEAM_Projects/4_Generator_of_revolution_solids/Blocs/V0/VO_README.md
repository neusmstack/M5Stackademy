# V0 – Generator of Solids of Revolution (Color Sensor Prototype)

## 🛠️ Overview

This is the first prototype of the Generator of Solids of Revolution project.

- Uses **Color Sensor** to detect colored LEGO shapes.
- Developed in **M5Stack UIFlow 2.0**.
- Displays detected shape and generated solid visually.

## 📋 Folder Contents

- `/Blocs/`  
  `Generator_of_Solids_of_Revolution.m5f2`  – Main UIFlow program.

- `/Images/`  
  Pictures of hardware setup and detection examples.

  ## 📌 Version V0: Generator using Color Sensor (UiFlow 2.0)
