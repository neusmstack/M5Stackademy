# Educational Resources for Radio FM Project

This folder contains all the pedagogical materials related to the Radio FM project. These resources are designed to support teaching and learning decimal numbers and their applications in a STEAM and curricular context.

## Contents

- **Theory sheets**: Didactic explanations about decimal numbers aimed at 1st and 2nd year ESO students.
- **Exercises**: Practice tasks related to decimals such as ordering, rounding, and calculations based on radio frequency decimals.
- **Competency problems**: Real-world problems linking the Radio FM project with decimal math concepts.
- **Solutions**: Answer keys for all exercises and problems.

## Usage

Teachers can use these materials to complement their lessons, adapt the exercises to their students' needs, and foster hands-on learning through the Radio FM hardware project.
